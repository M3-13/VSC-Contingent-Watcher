# Make your quota last

- **Use included models for routine work.** Models with a 0x multiplier do not use your allowance. Explanations, small edits and boilerplate rarely need more.
- **Save premium models for hard problems.** Architecture, tricky bugs and large refactorings are where they pay off. The model picker shows each model's cost.
- **Completions and next edit suggestions are free.** They do not use your allowance.
- **Pick the right mode.** Agent mode can use many requests per task. For small, well-defined changes, Ask or Edit is cheaper.
- **Give context up front.** Attach `#file`, `#selection` or error output so the first answer is right.
- **Batch your questions.** One prompt with three related questions beats three prompts.
- **Start a new chat per topic.** Long histories cost more and degrade answers.
- **Write `.github/copilot-instructions.md`.** Put recurring conventions there instead of repeating them.
- **Set a spending limit** in your GitHub billing settings, so overages never surprise you.

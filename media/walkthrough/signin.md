# Sign in with GitHub

Copilot Contingent Watcher reuses the GitHub account you already use in VS Code. There is no separate login and no token is stored by the extension.

1. Run **Copilot Contingent: Sign in with GitHub** (or click the person icon in the status bar).
2. Approve the GitHub sign-in prompt in VS Code.
3. The status bar fills with your quota within a few seconds.

If you use several GitHub accounts, pick the one that has Copilot.
